# ABETWORKS WORKCRM Startup Instructions

## Running with Docker (Recommended)

The easiest way to run ABETWORKS WORKCRM is using Docker:

1. Make sure Docker and Docker Compose are installed
2. Run the setup script:
   - On Windows: `setup.bat`
   - On Linux/MacOS: `chmod +x setup.sh && ./setup.sh`
3. Access the application at: http://localhost:3000

## Running without Docker (Development)

If you want to run without Docker for development:

1. Make sure you have PostgreSQL and Redis running locally
2. Update your .env file with local database settings:
   ```
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=abetworks_workcrm
   DB_USER=postgres
   DB_PASSWORD=your_local_password
   REDIS_URL=redis://localhost:6379
   ```
3. Run the application:
   ```bash
   npm install
   npm run build
   npm start
   ```

## Default Super Admin Account

After initial setup, a super admin account is created automatically:

- **Email**: `superadmin@abetworks.com`
- **Password**: `SuperAdmin2023!`
- **Role**: `abetworks_super_admin`

> **Important**: Change the default password immediately after first login!

## API Endpoints

Once running, the application provides the following key endpoints:
- `POST /api/auth/login` - User login
- `GET /api/customers` - Get customers
- `GET /api/leads` - Get leads
- `GET /api/deals` - Get deals
- `GET /api/tasks` - Get tasks
- `GET /api/users` - Get users
- `GET /health` - Health check

## Docker Compose Services

The Docker setup includes:
- Application server (Node.js)
- PostgreSQL database
- Redis cache
- Nginx reverse proxy
- Automated backup service

## Environment Variables

Required environment variables are automatically generated by the setup script, but can be customized in the `.env` file.
